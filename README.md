Project : Machine Learning-Based Classification of Forming Stages & FLC Estimation in Aluminum Alloy Forming
Description:
Developed a machine learning solution using Random Forest to classify critical stages in the sheet metal forming process of aluminum alloy (AL-5083). The project aimed to automate formability analysis and support the construction of Forming Limit Curves (FLCs), replacing manual expert evaluation with data-driven decision-making to enhance manufacturing efficiency.
Responsibilities:
•	Designed and trained a Random Forest classifier to categorize four key deformation stages in the forming process: Uniform Forming (C0), Diffuse Necking (C1), Local Necking (C2), and Crack Formation (C3).
•	Collected and preprocessed numerical and image-derived features from AL-5083 plates at various forming stages, with expert-verified labels.
•	Engineered features from image data using statistical and texture analysis methods (e.g., histogram-based, GLCM) for model input.
•	Integrated classification outputs with strain data to construct Forming Limit Curves and identify safe forming zones.
•	Estimated major and minor strains at the Local Necking (C2) points for plotting the Forming Limit Diagram (FLD).
•	Reduced reliance on traditional destructive testing methods such as Nakajima tests, improving both cost-effectiveness and process throughput.
•	Communicated findings in internal technical presentations and supported the digital transformation initiative for metal forming analysis.
Environment:
Python, scikit-learn, OpenCV, NumPy, Pandas, Matplotlib, Jupyter Notebook, Git, Windows/Linux
